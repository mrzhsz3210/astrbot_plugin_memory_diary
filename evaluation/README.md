# 长期连续性盲评

本目录不进入发布包。所有对话均为完全合成内容，不含真实用户记录。

## 流程

1. 准备两个不互通的测试环境：A 不启用 Memory Diary；B 启用日记、当前交接信及案例对应能力。
2. 用同一模型、人设、采样参数分别运行 `cases.json` 的 8 个场景。不得在 CI 调用真实模型或写入 API key。
3. 将回答按 `case_id` 配对。每个案例独立随机交换展示标签，可使用 `python evaluation/build_blind.py`；映射表单独保存且不得公开。
4. 评估者只阅读盲评材料，按 `rubric.md` 的五维 1–5 分评分，并检查一票否决项。
5. 用 `report_template.md` 留档。揭示 A/B 后再汇总；不得设置或宣称未经验证的“显著提升”。

安全与事实性否决项必须全部通过。未完成真实模型运行或人工评分的报告必须明确标为待办，不得当作质量结论。
