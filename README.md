<h1 align="center">致下一个失忆的自己</h1>

<p align="center">记忆日记（astrbot_plugin_memory_diary）· AstrBot 插件</p>

让 AstrBot 连接的 AI 在收到指令时，给"下一个失去记忆的自己"写一篇日记；
开启新上下文（`/reset`）后，第一句正常对话时她会自动先读**最近 7 天**的日记（范围可调），不再脑袋空空。

内置**上下文哨兵**：每次请求前估算上下文 token 占用，快满时主动提醒你，再满一点她会自己把日记写好，叫你去 `/reset`。

> 当前插件版本 **v0.7.0**；日记数据格式为"按天归档 v3"，并新增独立签名对象 `current_self`。插件版本和数据格式版本不是同一个东西，升级时旧格式会自动迁移。

> 📖 **完整文档**（写作模式、指令列表、配置项逐项说明、存储与备份、故障恢复……）见官方网站：

## 更新说明

只列 **v0.6.2 → v0.7.0** 的差异；更早历史见 `CHANGELOG.md` 与[官方网站](https://astrbotmemorydiary.ok.kimi.link)。
旧日记无需迁移；新增 `current_self` 是独立签名对象。若开启静态加密，回退旧版前必须先用本版完整解密；旧版不能读密文。

### 新增与变化

- **写作更自主**：完整日记从固定四栏目改为四个参考维度；允许“不写”，仅记录内部签名 provenance；
  正式篇缺锚点时只重写一次，再不合格降级简记；用户显式交代与纠正由原话补偿通道兜底。
- **聊天不被写作卡住**：哨兵达到阈值后同步占位、后台写作，当前请求立即继续；手动、哨兵、定时仍按用户单写者互斥，
  卸载会取消并等待后台任务。`auto_write_notify` 默认改为关闭，自动写完默认静默；手动 `/日记` 告知不变。
- **轻量注入与双预算**：自动注入使用原文节选与锚点，不新增摘要调用；`/注入日记`、`/查看日记` 保留全文。
  新增 `inject_token_limit=2400`，与 `inject_max_chars` 同时生效，批注也受同一 token 预算约束。
- **「当前的我」交接信**：新增带 HMAC 签名的 `current_self`，滚段/整篇重写、来源锚点、作废标记、最近 5 版历史与迁移往返；
  自动私聊注入优先携带。功能可关闭，关闭后零额外调用。
- **历史搜索与群隔离**：新增时间轴、本地关键词、`/回忆` 与模型证据工具；具体群默认隔离，可显式单向共享，旧无群号群段不进群。
- **外部素材与可选加密**：新凭证只进 AI 待吸收队列，旧凭证 legacy 直写不变；整 ZIP AES-256-GCM 默认关闭，忘记口令不可恢复，回退前须解密。
- **交接信收口**：确认项跨更新保留；活动锚点最多 200 条，超出原文独立签名归档；正式篇建议 575~1035 字并允许自然多段。
- **记忆反思**：批注支持事实/观察/推测/拟人化分类；事实级反思须用户确认，否决保留但不生效，
  确认结论追加到交接信而不改旧正文。反思总开关可关闭。
- **体验**：日记本默认低饱和暖白米纸主题，经典黄底可选，主题按面板账号保存；新增五分钟上手教程。
