<h1 align="center">致下一个失忆的自己</h1>

<p align="center">记忆日记（astrbot_plugin_memory_diary）· AstrBot 插件</p>

**轻量级上下文连续性插件：在会话重置/上下文耗尽时，用日记归档和最近日记注入缓解失忆感。**

> 📖 **官方静态文档站：[astrbotmemorydiary.ok.kimi.link](https://astrbotmemorydiary.ok.kimi.link)**
> 使用者手册、管理员手册、配置说明、共存建议与完整更新记录都在这里。

让 AstrBot 连接的 AI 在收到指令时，给"下一个失去记忆的自己"写一篇日记；
开启新上下文（`/reset`）后，第一句正常对话时她会自动先读**最近 7 天**的日记（范围可调），不再脑袋空空。
需要更早的细节时，可通过 `/回忆`、模型工具或 Web 时间轴按需定位旧证据，并回源到日期、场景与原文。

内置**上下文哨兵**：每次请求前估算上下文 token 占用，快满时主动提醒你，再满一点她会自己把日记写好，叫你去 `/reset`。

> 当前插件版本 **v0.7.4**；日记数据格式为"按天归档 v3"，并保留独立签名对象 `current_self`。插件版本和数据格式版本不是同一个东西，升级时旧格式会自动迁移。

> 📝 **用户调研**：如果你用过「记忆日记」，欢迎填一下[这份问卷](https://v.wjx.cn/vm/O37Ws86.aspx#)（约 4–5 分钟）。
> 想了解真实使用体验、最痛的地方和下一版最该改什么；匿名为主、联系方式选填，不收集聊天记录、日记内容或配置，结果只做汇总。

## 开箱即用与简短使用手册

**绝大部分用户可以开箱即用，无需进行配置项更改。如果有需求，请查阅[官方静态文档站](https://astrbotmemorydiary.ok.kimi.link)。**

默认已经开启最近日记轻量注入、当前交接信、批注、人设口吻与本地证据搜索；查询扩展、候选重排、自动召回、静态加密、插图和定时自动写默认关闭。白名单为空＝允许所有用户。模型上下文窗口的 60000 是保守起点，了解模型实际上限时再调整即可，不必为了开始使用先研究配置。

### 第一次使用

1. 安装并在 AstrBot WebUI 重载插件；
2. 像平时一样聊天，重要的事可以发 `/记一下 内容`；
3. 想主动留一篇记录时发 `/日记`，需要完整日记时发 `/日记 完整`；
4. 发 `/reset` 后正常说一句话，她会先读交接信和最近日记再接着聊；
5. 想找更早的内容，用 `/回忆 关键词`，会返回日期、场景、原文片段和出处。

### 常用指令

| 指令 | 用途 |
| --- | --- |
| `/记一下 内容` | 把重要事项留到下次写日记时重点记录 |
| `/日记` | 写简记；`/日记 完整` 写完整日记 |
| `/回忆 关键词` | 按需查找旧证据；`/回忆 全部 关键词` 查看全部类型，`/回忆 私人随笔 关键词` 回查 AI 私人随笔 |
| `/查看日记` | 在私聊里翻阅自己的日记 |
| `/日记状态` | 查看上下文占用、日记更新和注入状态 |
| `/日记帮助` | 查看完整指令与用法 |

### 我们的优势

- **叙事不是机械档案**：日记、批注、当前交接信和人设化反馈保持同一个“她”的口吻，重在其人其事的连续感。
- **原文可以回源**：需要时通过内存 SQLite FTS 找旧证据，返回日期、场景和原文片段，不把模型生成内容当作历史证据。
- **默认足够轻量**：不要求向量数据库、Embedding 或额外 Rerank 服务，基础检索异常会回退线性搜索。
- **边界清晰**：群与白名单隔离，用户记录、AI 私人随笔、外部素材和旧未分级记录分别标注；支持导出、验证备份与可选静态加密。

### 与其他记忆插件共存

同时安装 LivingMemory 或 [MemoryCompanion](https://github.com/menglimi/astrbot_plugin_memory_companion)（我会牢牢记住你）时，建议由**记忆日记负责叙事和默认连续性**。MemoryCompanion 可保留整理、管理和检索能力，但请管理员设置 `memory_injection.enabled=false`，避免重复注入；LivingMemory 建议使用独立实例，或通过 MemoryCompanion 的迁移功能处理，不让多套记忆同时主导聊天。详细说明见[官网共存建议](https://astrbotmemorydiary.ok.kimi.link/#/admin/config)。

### 与[「我会永远陪着你」](https://github.com/menglimi/astrbot_plugin_private_companion)联动（v0.7.3 新增）

适配陪伴插件 7.0.7 起的官方外部记忆接口，**纯软依赖**：没装、版本不符或连接失败时，记忆日记一切照旧。同装后，私聊里的日记注入改为对方按话题**精准召回原文片段**（带日期出处，防双注入自动让位）；对方「陪伴小屋」出现记忆日记的摘要卡；可选接收对方角色日记的签名存证副本。默认配置即为自动协作形态，无需手动调整。互补增益与边界（含 token 成本叠加、与 MemoryCompanion 同装时的单 writer 语义、对方 7.1.6 的已知注册表问题）逐条见完整文档「联动声明」一节。

### 修复：日记素材混入框架脚手架

- **写作前剥离固定形状机器文本**：会话历史与显式交代素材会移除 `system_reminder` / `system-reminder`、语音回执旁白及拆行后的 User ID、时间戳残片；未闭合提醒只吃到本行行尾，真实发言保留。
- **显式交代不再重复追加**：确定性补齐前再次清洗原文，并通过双向子串识别模型已经写出的交代。
- **引号内转述不触发显式交代**：避免语音旁白引号里的“记得”等词冒充用户本人交代；保守取舍是整句放在引号内的真实交代可能漏召。
- **既有数据不自动改写**：本版不修改旧日记、provenance 或签名；存量脏数据清理由独立脚本另行交付，不随发布包提供。
