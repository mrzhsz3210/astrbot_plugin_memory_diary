<h1 align="center">致下一个失忆的自己</h1>

<p align="center">记忆日记（astrbot_plugin_memory_diary）· AstrBot 插件</p>

让 AstrBot 连接的 AI 在收到指令时，给"下一个失去记忆的自己"写一篇日记；
开启新上下文（`/reset`）后，第一句正常对话时她会自动先读**最近 7 天**的日记（范围可调），不再脑袋空空。

内置**上下文哨兵**：每次请求前估算上下文 token 占用，快满时主动提醒你，再满一点她会自己把日记写好，叫你去 `/reset`。

> 当前插件版本 **v0.6.1**；日记数据格式为"按天归档 v3"。插件版本和数据格式版本不是同一个东西，升级时旧格式会自动迁移。

## 更新说明

只列 **v0.6.0 → v0.6.1** 的差异；更早的累积历史见 `CHANGELOG.md` 与[官方网站](https://astrbotmemorydiary.ok.kimi.link)。
数据格式与目录结构零变化，v0.6.0 直接覆盖升级即可，无需迁移。

### 修复

- **`/reset` 识别被其他插件追加的文本污染**（issue #2 关联）：`astrbot_plugin_qq_tools` 等插件会往消息文本尾部追加
  `[MSG_ID:...]` 之类的机器标记，导致插件对 `/reset` 的精确匹配失败——重置标记不置位、下一轮跳过日记自动注入，
  表现为「reset 后她不记得日记」。现在匹配前会循环剥离尾部 `[XXX:...]` 标记（新函数 `strip_trailing_decorations()`），
  只用于判断、不回写消息原文；无其他插件的环境行为与 v0.6.0 完全一致。

### 新增

- ✨ **Web 日记本批量删除**：日记本页面左页目录每项新增复选框，勾选若干天后点顶栏「🗑 批量删除」；
  确认框列明将删除的天数与最新一天，并醒目提示**删除不可恢复、建议先「⬇ 导出日记」备份**；
  删除连带清理该天的签名、插图、批注、来源记录（与 QQ 侧删除相同的级联实现），
  全部删光时该用户的 zip 整体移除、用户卡片消失。设了查看密码的日记要先输密码，
  旧 zip 无主人信息时引导管理员输入一次 QQ 号全量验签；一次最多删 366 天（防呆保险丝）；
  Web 管理员操作不走 QQ 用户防刷冷却。
- ✨ **自动写日记完成后告知开关**（`auto_write_notify`，默认开启）：哨兵自动写、每天定时自动写完成后，
  是否按人设口吻私聊告知「日记写好了」；**关闭后静默写、不打扰**——日记照常保存、照常注入；
  写入失败的技术说明与手动 `/日记` 的告知不受影响；「每天定时自动写」总开关关闭时，
  本项在配置页自动折叠。
- ✨ **日记本用户下拉框显示主人 QQ**：原来下拉框只显示昵称——用纯不可见字符（零宽/填充字符）当 QQ 昵称时
  就是一片空白，分不清这本日记是谁的；现在显示「昵称（QQ xxx · N 天）」，昵称剥掉不可见字符后为空时
  降级成「QQ xxx（N 天）」；未解析出主人的旧 zip 保持原「（未知昵称）」文案。
