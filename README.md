<h1 align="center">致下一个失忆的自己</h1>

<p align="center">记忆日记（astrbot_plugin_memory_diary）· AstrBot 插件</p>

让 AstrBot 连接的 AI 在收到指令时，给"下一个失去记忆的自己"写一篇日记；
开启新上下文（`/reset`）后，第一句正常对话时她会自动先读**最近 7 天**的日记（范围可调），不再脑袋空空。

内置**上下文哨兵**：每次请求前估算上下文 token 占用，快满时主动提醒你，再满一点她会自己把日记写好，叫你去 `/reset`。

> 当前插件版本 **v0.6.2**；日记数据格式为"按天归档 v3"。插件版本和数据格式版本不是同一个东西，升级时旧格式会自动迁移。

> 📖 **完整文档**（写作模式、指令列表、配置项逐项说明、存储与备份、故障恢复……）见官方网站：
> [astrbotmemorydiary.ok.kimi.link](https://astrbotmemorydiary.ok.kimi.link)。

> 📝 **用户调研**：如果你用过「记忆日记」，欢迎填一下[这份问卷](https://v.wjx.cn/vm/YDNYun0.aspx#)（约 4–5 分钟）。想了解真实使用体验、最痛的地方和下一版最该改什么；匿名为主、联系方式选填，不收集聊天记录、日记内容或配置，结果只做汇总。

## 更新说明

只列 **v0.6.1 → v0.6.2** 的差异；更早的累积历史见 `CHANGELOG.md` 与[官方网站](https://astrbotmemorydiary.ok.kimi.link)。
数据格式与目录结构零变化，v0.6.1 / v0.6.1.1（hotfix1）直接覆盖升级即可，无需迁移。

### 新增

- ✨ **外部写入 API（issue #3 关联，场景分析与方案设计来自 @Sil-Future）**：第三方插件 / 脚本现在可以把"记忆"
  作为日记凭证写入日记，跨入口的记忆从此可以互通。新增 Web 端点
  `POST /api/v1/plugins/extensions/astrbot_plugin_memory_diary/note`，双闸鉴权——既要 AstrBot API key 的
  plugin 权限，又要插件侧 token（token 只存 SHA-256 哈希于 `external_write_tokens.json`，明文不落盘）；
  内容以「（外部·来源）」分隔条段落追加进当天日记正文、与日记 zip 原子重写落盘，**幂等写入**（同一 ext_id 重复提交
  不会产生重复段落）。上限 8 KB、不允许未来日期、ext_id 限 64 字符可打印 ASCII；
  每个 token 每分钟 20 次限流（超限 429）。分隔条来源支持显示名映射（配置「外部来源显示名」，
  如 `dsh=零陵香`，分隔条变「（外部·零陵香）」；只改展示，审计仍记机器标识）。
  完整使用说明见[官方网站](https://astrbotmemorydiary.ok.kimi.link)的「14 外部写入 API」一节。
- ✨ **`/日记凭证` 指令**：管理外部写入凭证（`新办 <来源标识>` / `列表` / `吊销 序号`），QQ 私聊使用；
  新办的凭证只显示一次，凭证本体不随列表外流。
- ✨ **存储接口稳定性承诺**（官网文档 §13.6）：向第三方明确承诺 zip 文件名派生规则与 zip 读取侧布局
  （条目、签名、来源侧车、插图、说明.txt）在本插件 v0.x 系列内稳定；明确不承诺写入侧契约——
  外部写入生态建立在 HTTP API 契约之上。
- 📄 **招募区新增视觉设计岗与「已有贡献」表**：视觉设计岗正式开放认领；@puppe110（issue #2）、
  @Sil-Future（issue #3）的认真反馈收录进「已有贡献」名单，排名不分先后。
- 🔧 **合入 v0.6.1.1 hotfix1**（手机端窄屏批量删除修复）：v0.6.1 的批量删除复选框在窄屏下被 `display: none`
  隐藏，手机端永远勾不了日期；hotfix1 把窄屏目录改为左侧抽屉修复。v0.6.2 已完整合入该修复，
  hotfix1 用户无感升级，直接覆盖即可。

### 修复（代码审查同批修复）

- 🛡️ **数据与安全**：删除日记后外部客户端重放旧写入不会再"复活"已删段落（删除留下墓碑去重键，
  重放返回 `replayed:true`）；旧格式日记迁移遇到验签失败整次中止、不再丢篇目；偏好文件损坏会备份为
  `.corrupt` 并拒绝覆盖（保护范围/备忘/查看密码）；缺签名的日记不再是"看不了也删不了"的死局。
- 🔐 **权限与闸门**：`/形象 修改`、`/形象 确认` 只有 AstrBot 管理员能执行（查看与重拟仍对白名单开放）；
  查看密码改为**页面内存短期令牌**，密码不再进 URL / 访问日志 / 浏览器历史，解锁后同一页面会话 30 分钟内
  免重复输入；「一键备份全部日记」明确为管理员信任域例外；「存到本机并打开位置」只认本机/代理链最后一跳。
- 🧠 **注入与上下文**：群聊里每个白名单用户都能各自读到自己的日记（此前只有第一个发言的人会被注入）；
  `/注入日记` 与自动注入不再同轮重复塞两遍；首轮请求失败后重发仍会注入（不再"整代失忆"）；
  带参数指令不再被其他插件的 `[MSG_ID:…]` 尾部标记打断。
- 🖼️ **插图**：生图期间删/重写日记不再让图复活或白扣额度；非图片响应按失败处理、不裂图；
  插图标记写坏时整段保留、不吞后文；「插图到了」提示按发送者分槽不串号。
- 🕒 **定时自动写日记**：中途重载/重启后当天没轮到的用户会被补写；错过窗口会在日志里说明原因。
- 🖥️ **日记本页面**：下载导出会先弹密码框（此前主路径只会报英文 403）；空态/删光后不再残留旧正文；
  读取失败会明确提示并清旧数据；下拉框按方向键不再误翻页；批量删除会提示本来不存在的日期。
- 🔤 **指令细节**：`²` 等上标数字不再让指令崩掉；`/删除备忘 N` 严格只删第 N 条；正文里的 `@` 不再被误剥。
